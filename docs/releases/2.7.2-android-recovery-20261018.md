# EasyTier 2.7.2 Android 恢复状态修复

本次保持应用版本 `2.7.2`，按预发布版本提供，仅更新 Android ARM64 APK 和 Web 静态页面。
Linux Core、服务端二进制、Windows 和 macOS 安装包不在本次更新范围内。

## 修复内容

- Android 同一网络的 TUN 重建成功后，清除属于之前请求的旧错误，避免后续轮询主动断开已经恢复的 VPN。
- 旧停止回调延迟失败时，不再污染新请求的状态。
- 仅在新请求完成 Android TUN 与 Core 附着后确认恢复；真实停止失败和系统撤销 VPN 权限仍保留。
- Web 网络成员列表移除无法区分配置的 `central: → central:` 摘要，保留部署状态与实际错误。

## 验证边界

两个关键回归在修改前失败、修改后通过；客户端状态与原生桥接逻辑的自动化回归，以及网络成员页面的中英双语浏览器回归通过。
管理重连测试覆盖断线、重新连接、认证中及认证成功，并验证不会因此停止已经建立的 VPN。

这些测试不等同于 Android 手机真机验收。Wi-Fi 与移动网络切换、锁屏及反复启停仍需在实际设备上复测；管理连接恢复也不能单独证明手机 TUN 正常。

APK 保留原应用标识、签名和 versionCode `2007003`，可覆盖安装。
请以此次修复发布的源码提交及文件摘要区分安装包，不能只用 `2.7.2` 版本号判断是否已经更新。
此前的完整多平台版本继续保留于
[`fix-2.7.2-20261018`](https://github.com/alniyata-firefly/easytier/releases/tag/fix-2.7.2-20261018)。
