## 修复内容

- 分别显示管理认证、Core 运行和 VPN 连接状态；打开应用建立管理连接，VPN 连接由用户操作。
- 修复 Android 连接、断开、后台恢复及系统撤销 VPN 后的状态处理，避免旧 TUN 状态覆盖新实例。
- 修复桌面本机、系统服务及远程 Core 的配置来源混用；补充手动网卡策略的 Core 能力检查。
- 完善重装设备的身份审批、网络成员配置清理和凭据保留。
- 增加按设备查看的管理连接历史和近期隧道事件。

## 验证与安装

原始构建来自
[Actions 38998168675](https://github.com/alniyata-firefly/easytier/actions/runs/38998168675)，
包括 196 项 Rust 定向回归，以及 Linux x64/ARM64、Windows x64、macOS Intel/Apple Silicon、Android ARM64 和 Web 构建。

交付时重新下载并校验了 CI 压缩包、全部安装包摘要、源码清单和 Web 文件。
Linux 发行二进制另行验证了设备审批、管理日志与重启留存、成员移除后的管理连接，以及真实 TUN 数据面通信。
本机数据面测试使用隔离网络和测试 TCP 转发，物理网卡发现及生产节点端点由部署验收分别核对。
安装前可用发布页的 `SHA256SUMS` 和 `build-manifest.json` 核对文件。

Android 保持应用 ID `com.kkrainbow.easytier.adapted`、原签名和 versionCode `2007003`。
这是同版本覆盖安装，不构成递增版本号的自动升级。
Android 已通过签名、嵌入 Core/前端及 DEX 生命周期校验，手机上的实际连接与反复启停仍需验收。
Windows/macOS 已完成构建与包内容验证，未进行 GUI/VPN 真机测试；macOS 未经过 Apple 公证。
