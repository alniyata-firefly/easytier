# 可选贡献工具

此目录主要保留 EasyTier 上游贡献的独立工具和平台集成，供源码研究与单独维护。它们不属于本分支默认的 React Web、GUI 或 Android 发布流程；目录存在不表示已有对应的下游安装包。

其中 Magisk 构建与更新地址仍使用上游发行渠道，不能作为本分支 Core 的安装或更新入口。`easytier-uptime` 的独立 Vue 界面也不是当前 React 管理控制台。

当前支持的构建与下载入口见 [仓库 README](../README.md) 和 [构建说明](../docs/github-actions.md)。各工具原始作者、许可证、依赖与技术标识继续保留。
